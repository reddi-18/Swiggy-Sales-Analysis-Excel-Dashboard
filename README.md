# 🍔 Swiggy Sales Analysis Dashboard | Microsoft Excel

An interactive Excel dashboard analyzing **197K+ Swiggy orders** to uncover sales trends, customer ratings, food preferences, and city-wise business performance.

## 📊 Project Overview

This project focuses on transforming raw food delivery data into meaningful business insights using Microsoft Excel. The interactive dashboard enables users to monitor key performance indicators (KPIs), explore sales trends, and compare performance across different categories, restaurants, time periods, and locations.

## 🎯 Key Performance Indicators

| KPI | Value |
|---|---:|
| Total Sales | ₹53.01M |
| Total Orders | 197.43K |
| Average Rating | 4.34 |
| Average Order Value | ₹268.51 |

## 🔍 Key Business Insights

- **City Performance:** Bengaluru recorded the highest sales among the top five cities, at approximately ₹5.5M.
- **Food Preference:** Non-Veg contributed approximately 64% of total sales.
- **Daily Sales:** Saturday recorded the highest daily sales, at approximately ₹7.78M.
- **Quarterly Performance:** Q2 generated approximately ₹19.9M in sales.
- **Sales Trends:** Monthly, weekly, and daily views help explore changes in business performance over time.

## 📈 Dashboard Features

- KPI cards for sales, orders, ratings, and average order value.
- Monthly sales trend analysis.
- Daily and weekly sales performance.
- State-wise sales, ratings, and order comparison.
- Top five cities by sales.
- Veg vs Non-Veg sales analysis.
- Quarterly performance comparison.
- Category-wise and restaurant-wise analysis.
- Interactive slicers for Month, Category, and Restaurant.
